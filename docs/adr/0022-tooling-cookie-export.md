# Preserve cookie export compatibility across CLI and browser profiles

If Chromium profile discovery finds no candidates, delegate profile selection to yt-dlp. Pass the chosen profile in its `BROWSER[:PROFILE]` argument form. Write the profile menu in one output call to keep its rows together before the prompt.

Validate exported Netscape records by their tab-separated domain, subdomain flag, path, secure flag, expiry, name, and value fields in that order. Preserve the surviving source lines, including the HttpOnly domain marker.

Configure UTF-8 and line buffering at CLI startup on streams that support
reconfiguration so importing the module preserves the caller's streams.

The input-file mode reads an explicitly supplied Netscape file and prints the
complete environment assignment without a browser, provider, or clipboard
subprocess. The legacy browser invocation passes a positional placeholder to
yt-dlp because its CLI requires a URL for that invocation. [Local-only export](https://github.com/Le-Who/ytdlbot/issues/153)
