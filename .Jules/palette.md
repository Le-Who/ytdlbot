## 2024-03-24 - Added SETTINGS_EMPTY state
**Learning:** Telegram bots lack traditional HTML interfaces, so UX improvements must focus on message clarity and state communication rather than ARIA labels or CSS. Empty states (e.g. unconfigured settings) are opportunities for user guidance.
**Action:** Replaced generic "—" empty fields with a descriptive `SETTINGS_EMPTY` text block to guide users when no settings exist.
