# Preserve the request behind each callback

A callback uses the request that created its menu, even when the same chat
opens another request. Persist selected highlight context for later item
actions. Accept legacy menu actions for the link-cache TTL. A legacy back
button reads conversation state, and a tokenless private slideshow uses its
message identity for work ownership.

Register work before publishing its cancel button. Retry claims check for a
completed predecessor again after asynchronous cache reads and reserve the
retry only after its UI is ready. This leaves a failed UI acknowledgement
retryable and prevents a stale cache read from reopening a completed operation.
User preferences can skip the generic picker, while the specialized Instagram
and X entry points retain their own selection behavior. Groups passively ignore
messages that have no supported URL. See [callback regressions](../acceptance.md#offline-acceptance).
