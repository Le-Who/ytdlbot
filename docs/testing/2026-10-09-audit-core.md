## Reproduced defects / missing safety tests

Priorities below describe test value and consequence; production fixes are out of current scope. Direct inline offline repro returned exit 0 and printed the stated results. Every repro used temp resources or controlled local fake boundaries.

1. **P1: worker cancellation leaves an untracked active handler.** app/core/drain.py:290 waits for process_task+heartbeat, catches cancellation at307, checkpoints, then finally only cancels heartbeat and removes process tracking at339. Cancel the task executing `_process_job` while a handler waits on Event. Output: `WORKER_CANCEL_OPERATION_ALIVE True tracked 0`. A recovered job can run while the old handler still performs delivery/resources. New test must cancel actual worker `_task`, assert handler finalized, no task/active-job leak, checkpoint recovery and no duplicate delivery. Existing drain cancellation test84 cancels the handler via controller; it does not cancel the supervising worker.

2. **P1: lease release cancelled on queue lock leaks capacity permanently.** app/core/download_queue.py:82 marks `_released` before awaiting `_release_slot` at83. Controlled queue lock: acquire lease, hold lock, start `lease.release()`, let it mark released and block, cancel it, release lock, retry lease.release(). It returns early and next acquire times out: `QUEUE_CANCELLED_RELEASE capacity lost`. New public-boundary test should assert BoundedSemaphore capacity and FIFO forward progress after cancellation during release. Sequential idempotency test75 does not exercise this.

3. **P1/P2: DiskReservation concurrent releases spend another owner's reservation.** app/core/resource_budget.py:226 checks `_released` before await, marks released only at240. Reserve A10 and B20, hold budget lock, concurrently call A.release twice, then release lock. Output `DISK_CONCURRENT_RELEASE_RESERVED 10 expected 20`. This permits subsequent jobs to overcommit disk. Add concurrent release and cancelled release tests with B's allocation asserted intact; current tests check only one release.

4. **P1: valid JSON with invalid lease shape crashes janitor.** app/core/resource_budget.py:51 and323 call payload.get without asserting dict; neither catches AttributeError. Sidecar `[]` causes `LEASE_CORRUPT_JSON AttributeError`. Both is_active_media_lease and marker_identity fail. janitor cleanup propagates this, and janitor_loop has no enclosing exception recovery. Add parameterized `[]`, `null`, string, missing owner, invalid expiry, NaN/Inf sidecars, assert file/sidecar recovery and subsequent loop cycle. Also test filesystem error during listdir.

5. **P2: drain deadline excludes checkpoint/cleanup duration.** app/core/drain.py:81 only times the initial asyncio.wait; gather checkpoints at93 and gather cancelled jobs109 are unbounded. Fake store checkpoint taking .1s with deadline .01s returned `DRAIN_DEADLINE_ELAPSED 0.125 deadline 0.01`. Cancellation-resistant handler or locked SQLite may exceed deploy grace by much more. Define deadline contract (whole drain versus work grace) and test slow checkpoint plus cleanup. Existing84 uses immediate real-store checkpoint and immediate handler finally.

6. **P2: startup failure retains worker singleton lease.** app/core/drain.py:152 acquires worker before `_requeue_startup_failures` at158; exceptions do not release. Requeue raises OSError, second worker acquires=False: `STARTUP_FAILURE_BLOCKS_NEW_OWNER True`. Add failure/cancellation at each post-acquisition stage and assert lease immediately releasable; periodic maintenance errors also need survival assertions.

7. **P2: expired claim can be renewed.** app/core/job_store.py:741 checks running+owner but no claim expiry/live worker. Inject clock: claim for1s, extend worker100s, advance2s; `renew_claim(...)=True`. Output `EXPIRED_CLAIM_RENEWAL True`. Worker renewal at662 explicitly rejects expiration and delivery finalization requires live claims. New ownership matrix should define whether resurrection is permitted, with expired same-owner/new-owner tests and no delivery authorization through stale claims.

8. **P2: failed delivery payload purged before next restart retry.** app/core/job_store.py:1028 purges both completed and failed; startup requeue994 considers failed-delivery rows regardless payload. With 1s retention, record failed item/fail job, advance2s, purge, requeue, claim -> `PURGED_FAILED_RETRY_PAYLOAD {'update_id': 2}`. Source URL/message is lost and recovered Telegram Update has no handler data. New retention matrix should distinguish completed, irrecoverable failed, retriable failed, accepted/checkpointed/running and verify no empty retries.

9. **P2: FileTTLCache duplicate and missing cleanup callbacks.** app/core/cache.py:9 calls super.popitem, whose internal pop dispatch also triggers override15. Capacity eviction gives `CACHE_CAPACITY_CALLBACKS ['A','A']`. Expiration inherited from TTLCache bypasses callbacks entirely: `CACHE_TTL_CALLBACKS []`. Tests/test_cache.py:18/28 use membership and39 explicitly permits duplicates, so resource contract is weakened. Assert one callback per physical removal with exact sequence/count, expiry using fake timer, overwrite/delete/callback exception semantics. `clear` on pinned cachetools produced exactly ['B','C']; do not claim clear currently duplicates.

## Other evidenced risks (static analysis; not all production defects)

- **Redis clear blast radius:** app/core/storage/redis_storage.py:88 executes FLUSHDB even for prefixed caches. tests/test_storage_redis.py:116 asserts FLUSHDB instead of asserting namespace isolation. State storage shares Redis among lnk/inf/can/gifdoc/prefs/ratelimit/media-cache. Test fake Redis keys across these namespaces. Decide intended clear contract explicitly; callsites currently do not clear production caches, so urgency is lower than an active destructive path.
- **Transaction BEGIN cleanup:** job_store.py:1054 allocates connection before __enter__; if BEGIN IMMEDIATE raises, __exit__ never closes it. write_probe has correct explicit finally but other transactions do not. Add bounded-contention test with instrumented connection.close for failed BEGIN, repeated lock failures and subsequent success.
- **Cancellation of to_thread commits:** job_store._run402 delegates a DB operation to asyncio.to_thread; cancelling caller does not stop transaction. A durable webhook cancellation can commit after response/error. Must verify retry deduplication/recovery across actual commit race, rather than assume cancellation rolled back.
- **Unhandled stderr reader failure:** process.py:667 awaits stderr_task and only catches TimeoutError; a readline exception prevents `_finish`671, leaves slot/owner/tree registration. Add failing stderr boundary then verify slot reusable/process absent/tree closed. Existing mocked core_process success/cancel do not expose this.
- **POSIX process tree normal finish:** process.close_tree330 performs tree cleanup only on Windows. Existing parent-exit descendant tests are Windows-specific. Linux CI/deploy needs a real parent spawning detached-stdio child, then assert no surviving child after normal finish/cancel, including SIGTERM-resistant descendant.
- **Config validation inconsistencies:** MAX_CONCURRENT_TASKS=0/MAX_API_TASKS=0 create deadlocking semaphores; LIMITER_*_REFILL=0 gives division-by-zero on memory startup; negative refill can silently corrupt model. Positive_int is applied only media/cloud limits; floats/timeouts accept NaN/Inf. Isolated subprocess environment matrix should assert deterministic, explanatory startup behavior and clean env (do not inherit developer .env implicitly).
- **Cookies host routing:** get_cookies_path compares keyword anywhere in full URL; domain/query lookalikes can choose wrong platform cookies. VK override lacks vkvideo.ru although downloader supports it. Test exact hostname/subdomains/negative domain+query aliases; currently tests only expected strings and files exist.
- **User prefs mutable alias/lost merges:** MemoryStorage returns same dict, Redis returns a decoded copy. Concurrent Redis set_prefs read/merge/write can lose fields, memory caller mutation can change cached state without set. Include shared contract tests only after defining intended atomicity/copy guarantees.
- **Metrics format:** metrics.py labels are inserted raw into exposition at276/301/308. Quote/backslash/newline release/provider values can yield invalid Prometheus text. Current tests search strings only; parse rendered text and check exact counter/summary samples, including escape cases.
