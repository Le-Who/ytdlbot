# Scope the media settings to their supported callers

Keep legacy pipe, cookie, and platform-proxy settings available for legacy service callers. The public pipeline routes through bounded disk materialization and validation, uses its own verified provider eligibility, and keeps proxy affinity across resolution, probes, and transfers. Configure public routes through the shared platform allowlist and ordered proxy pool.
